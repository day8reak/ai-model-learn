# 课程讲义

每个课号对应一份讲义，讲解、例子和自测题集中维护。

讲义中的结构图、流程图和数据映射图与文字一起阅读。内嵌 Mermaid 图可在 GitHub 的 Markdown 页面显示，详见 [GitHub 图表说明](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams)；本地阅读器若只显示代码块，可在 GitHub 查看。每图附读图说明；示意图省略的细节以正文为准。

图中关系需对照原始资料核查，形状与教学例子单独计算；[核查约定及记录](../docs/diagrams.md)区分内容核对和显示检查。

学习状态以[进度](../docs/progress.md)为准；顺序见[路线](../docs/roadmap.md)。日期、答题反馈和暂停位置记入[学习日志](../study-log/README.md)。已掌握或跳过后的总结见[知识索引](../notes/README.md)。

## 近期课程计划

更新于 2026-10-13。从当前待学的 T003 开始，先列接下来 12 个主题；以下是目录，讲义尚未生成。顺序可随学习反馈调整，复杂主题可拆成子课，不对应固定日期。每次归档或调整方向时向后补足至少 10 个待学主题，已开始的课号和讲义保持可追溯。

| 顺序 | 课号 | 主题 | 学完能够做什么 |
| --- | --- | --- | --- |
| 1 | T003 | 张量形状、矩阵乘法与广播 | 从 `[B,S,H]` 推导线性投影的输出，判断矩阵能否相乘 |
| 2 | T004 | Self-Attention 与 Q/K/V | 解释查询、键和值的作用，用小例子追踪信息汇集 |
| 3 | T005 | 因果掩码与 softmax | 遮住未来位置，将分数变成权重并手算加权结果 |
| 4 | T006 | 多头注意力与输出投影 | 追踪拆头、各头计算、拼接和输出投影的形状 |
| 5 | T007 | 位置编码与 RoPE | 解释词向量之外如何引入位置，观察旋转对注意力的影响 |
| 6 | T008 | FFN、激活与门控 | 拆解线性层、激活和门控，追踪中间维度变化 |
| 7 | T009 | 残差、LayerNorm 与 RMSNorm | 手算小向量的归一化，区分残差相加和尺度调整 |
| 8 | T010 | LM Head 与下一个 token 的选择 | 从隐藏向量得到词表分数，对比贪心、温度与采样 |
| 9 | I001 | Prefill：处理输入提示词 | 画出多个输入 token 的计算，定位首次输出所用的分数 |
| 10 | I002 | Decode：逐步生成 | 追踪新 token、逐层计算、状态更新和停止条件 |
| 11 | I003 | KV Cache：缓存什么、为什么可复用 | 对比有缓存与重计算，说明缓存的内容和复用条件 |
| 12 | I004 | KV Cache：容量、位置与生命周期 | 估算缓存大小，跟踪追加、位置、清空与请求隔离 |

讲义准备时配上经核查的图示、具体例子和自测；这里只维护主题和目标。完成基础后，再按[模型演进表](../docs/model-evolution.md)穿插六个模型系列，不提前排死全部课程。
