### 1. Qwen4-Max 正式发布

**公告日期：2026-11-16。** 此前已报道预览版，本次正式模型通过 Token Plan 和 API 提供。官方公布其采用 MoE（混合专家）结构，总参数 2.4 万亿、每个 token 激活约 710 亿参数，支持原生视觉和百万 token 上下文；较小规模开放权重版本仍属后续计划。[官方公告](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max?_p_lc=1)

**对推理的影响：**工程判断是，总参数量与每步参与计算的参数量需要分别评估；激活参数减少，仍需结合访存、通信和负载测量实际延迟。

**建议：现在了解正式开放范围；专家路由与部署成本以后学习。**

### 2. 腾讯发布 Hy4 flash

**公告日期：2026-11-16。** 模型总参数 2240 亿、激活参数 120 亿，支持多模态与百万 token 上下文。官方介绍采用混合注意力，并结合四位量化等推理优化；已在 TokenHub 等产品上线，开源仍为后续计划。[官方公告](https://www.tencent.com/zh-cn/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/)

**对推理的影响：**据其设计，效率优化同时涉及模型结构、数值精度和执行实现；评估时应固定输入输出长度，同时检查质量、内存与耗时。

**建议：现在了解这些优化层次；混合注意力与量化以后学习。**
