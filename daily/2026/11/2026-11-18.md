### llama.cpp 扩展 OpenCL 对非连续张量的支持

2026-11-17，llama.cpp 在构建 `b12466` 中更新了 SiLU（逐元素激活函数），支持半精度浮点数输入，也能处理内存不连续的单精度浮点数输入。对推理的影响是，即使切片后相邻元素在内存中隔着一段距离，这条计算路径也能直接处理该输入。[合并说明](https://github.com/ggml-org/llama.cpp/pull/32319) · [构建记录](https://github.com/ggml-org/llama.cpp/releases/tag/b12466)

**现在了解**形状相同的两个张量可以有不同的内存布局。**以后学习**步长如何决定算子到哪里读取下一个元素。

### OpenAI 发布 GPT-6.2 Astra 与 Sol

2026-11-17，OpenAI 的 API 上线两款模型。Astra 面向复杂推理与编程，Sol 面向日常编程和智能体任务。官方报告两者在部分复杂任务中使用了更少的输出 token。评估推理效率时，即使每秒生成的 token 数相同，完成一次正确回答所需的生成时间也可能因输出长度而不同。[发布公告](https://openai.com/index/introducing-gpt-6-2-astra-sol/) · [API 更新记录](https://developers.openai.com/api/docs/changelog)

**现在了解**生成速度和完成任务的总耗时是两个指标。**以后学习**在相同题集上同时比较正确率、输出长度与耗时。

### 微软发布可调节思考强度的 MAI Code 2 系列

2026-11-17，MAI Code 2 与较小的 Flash 版进入 GitHub Copilot。两者均支持约百万 token 的上下文和五档思考强度。这给推理评估增加了一个变量：同一模型处理同一段代码时，所选档位也会影响回答质量、等待时间和成本。[微软模型卡](https://microsoft.ai/pdf/MAI-Code-2-And-MAI-Code-2-Flash-Model-Card.pdf?v=2) · [GitHub 发布公告](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot/)

**现在了解**上下文长度表示一次请求能容纳多少内容。**以后学习**固定代码和问题，只改变思考档位，比较额外耗时是否换来更多正确修复。
