## 记录约定

- 交互学习时更新当天文件和本索引；每日自动任务只读取，不代填学习经历。
- 多课按课号分段。保留初次回答、必要纠正和最终反馈，不因后续掌握而删除理解过程。
- 只记录可公开的技术学习情况，不放私人对话、环境凭证或工作项目内容。
- 理论理解、CPU 实现、设备验证和性能优化分别记录，不从答对自测推断已完成工程实践。
