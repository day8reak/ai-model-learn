## 定义与核心结论

token 是文本经过切分后的处理单位，token ID 是单位的整数编号，词表保存单位与编号的对应关系。单位可能对应一个字、多个字或词的一部分，实际结果取决于 tokenizer。ID 的数值大小不代表重要程度，也不表示语义距离。[Hugging Face 官方课程](https://huggingface.co/learn/llm-course/en/chapter2/4)

序列长度 S 统计一次输入中的位置数；词表大小 V 统计可用单位总数。同一 token 可以重复出现，因此 ID 表示身份，位置表示顺序。

## 教学例子与形状

固定教学词表为 `{我:0, 喜欢:1, 大:2, 模型:3, 。:4, 你:5}`，暂不加入特殊 token。

`你喜欢模型。` 按本例约定切分成 `[你, 喜欢, 模型, 。]`，对应 `[5,1,3,4]`，S=4、V=6。若 B=1、H=4，则 ID 张量形状为 `[1,4]`，Embedding 后为 `[1,4,4]`；计算所有位置输出头时，logits 形状为 `[1,4,6]`。

教学演示可运行：

```python
vocab = {"我": 0, "喜欢": 1, "大": 2, "模型": 3, "。": 4, "你": 5}
tokens = ["你", "喜欢", "模型", "。"]
print([vocab[token] for token in tokens])  # [5, 1, 3, 4]
```

这段代码只演示切分完成后的查表，不实现分词算法；已用 Python 3 执行核对，不据此记录学习者已完成模型实践。

## 词表必须与权重匹配

只交换“我”“你”的 ID、保持权重不变，会破坏文字与 Embedding 行、输出候选索引的对应关系：新词表把“我”编码为 5，权重第 5 行仍保留原来对应“你”的参数；模型选出 ID 0 时，新词表会显示“你”。

这是编号解释错配，不是序列位置交换。输入错配还会改变后续计算，不能断言输出只会把整句里的两个字简单互换。实际部署需使用模型配套的 tokenizer；普通调用不会自行重新安排编号。
