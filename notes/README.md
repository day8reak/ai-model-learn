# 知识索引

这里只收录用户确认掌握或明确要求跳过后整理的知识笔记。日常讲义保存在 `daily/`，不自动算作正式归档。

| 分类 | 目录 | 内容 |
| --- | --- | --- |
| 基础 | `foundations/` | 推理、token、张量、概率 |
| 模型结构 | `architecture/` | Attention、Transformer、MoE |
| 模型演进 | `models/` | 千问、DeepSeek 等具体版本的差异与配置 |
| 推理机制 | `inference/` | Prefill、Decode、KV Cache、性能指标 |
| 优化 | `optimization/` | 量化、批处理、缓存、推测解码、算子优化 |
| 部署 | `deployment/` | 引擎、硬件、服务与验证 |
| 硬件基础 | `hardware/` | 内存、布局、流水、同步与性能分析 |
| 算子 | `operators/` | 参考实现、NPU 实现、误差与性能 |
| 面试练习 | `interviews/` | 已学习主题的推导与工程追问 |
| 前沿 | `frontier/` | 有来源和适用边界的新技术 |

首次归档时创建对应目录。文件示例：`foundations/B001-what-is-inference.md`。

## 笔记内容

记录知识编号、分类、状态、归档日期、前置知识、定义、核心原理、具体例子、误区、适用边界和来源。已掌握笔记补充用户提问与理解过程；已跳过笔记保留简明摘要与跳过原因，不虚构自测通过记录。

技术笔记尽量包含公式、张量形状、状态读写和最小实验。分别标注理论理解、CPU 参考、NPU 验证和优化状态，附真实证据。公开时将反馈整理为通用技术问题，不保存私人对话、内部项目数据或账号信息。
