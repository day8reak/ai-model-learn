# 面经补充与自测

面经用于发现知识缺口和练习表达，不替代课程、原始资料或实践。不把一篇帖子等同于完整公司题库，也不据此声称某题是行业高频。

## 已阅读来源

[模型部署/推理优化/高性能计算方向社招面经总结](https://www.nowcoder.com/discuss/599177965083054080)，作者 Litt1e0range，2024-03-18，访问于 2026-10-09。个人经历涉及 kernel 调试、内存访问、执行开销与算子手写；CUDA 细节需要与通用 NPU 思路区分。

下列题目是结合学习目标重新设计的练习，不是该帖逐字摘录或全部出自该帖的真题。

## 阶段题目

| 阶段 | 自测题 | 回答应包含 |
| --- | --- | --- |
| Transformer | 推导 Q/K/V、注意力分数和输出的形状 | 维度、掩码方向和数值例子 |
| 推理 | 为什么因果自回归生成能缓存 K/V？什么时候缓存失效？ | 依赖关系和复用条件 |
| 缓存 | 给定层数、KV 头数、维度、长度与 dtype，估算容量 | 单位及公式对 MLA/混合层的边界 |
| 性能 | Prefill 与 Decode 为什么常有不同瓶颈？什么时候不成立？ | 形状、并发、计算/搬运量和测量方法 |
| Attention | FlashAttention、分页缓存、滑窗、线性注意力各改变什么？ | 算法、存储、可见上下文和状态的区别 |
| MoE | 激活参数少，为什么仍可能耗内存或较慢？ | 总权重、路由、通信、负载和小矩阵 |
| 投机 | 草稿被拒绝后为何不能只删输出 token？ | KV/递归状态、位置、采样与参考对照 |
| 算子 | 实现稳定 softmax，如何处理不整齐的形状？ | 分块归约、尾块、误差和重复验证 |
| 硬件 | 双缓冲何时没有收益？ | 数据依赖、搬运/计算比例和资源代价 |
| 整模型 | kernel 加速了，模型反而变慢，如何排查？ | 热点占比、布局、同步、回退和 profile |

答案在学习对应主题时补充，并附原始资料或实验。注意力题核对 [FlashAttention](https://arxiv.org/abs/2205.14135)与 [PagedAttention](https://arxiv.org/abs/2309.06180)；双缓冲题对照[官方案例](https://www.hiascend.com/zh/developer/techArticles/20240819-1)。每课最多一道相关追问，阶段复习采用“解释 → 推导 → 最小实现 → 失败案例”。
