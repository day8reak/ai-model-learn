## 状态约定

`待学习 → 学习中 → 已掌握`；用户说“太简单 / 已了解 / 跳过”时，可转为`已跳过`。

“已掌握”和“已跳过”都需要知识文档和索引记录。只有用户反馈才能触发这两种状态；每日自动生成不能替代用户反馈。先完成归档，再将下一知识点标为“待学习”，默认次日开始。用户明确要求当天继续或跳过换课时才提前推进；“明天再学 / 今天结束”优先。

“今天结束”记录当日学习停止，不单独触发掌握或跳过；保留当前主题和待反馈位置，后续从这里接续。

本页只汇总当前状态与安排。课程正文按课号保存在 `lessons/`，实际日期、答题与纠正、暂停及掌握确认记入 `study-log/`；每日动态保存在 `daily/`，不决定学习进度。

调整路线暂时搁置的内容标记“暂缓”，不等同于已掌握或已跳过。实践状态单独记录。
