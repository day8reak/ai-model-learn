# 大模型推理学习

从 Transformer、Prefill、Decode、KV Cache 开始，沿千问、DeepSeek 等开源模型从早期到最新公开版本学习结构与优化，建立可复习、检索和实践的中文知识库。

目标是逐步具备独立开发 NPU 算子、打通整模型推理和完成端到端优化的能力。先学通用原理，之后再选平台；通过参考实现、设备验证和性能实验验收能力，不把理解结构等同于已经能够交付所有模型。

公开仓库：[day8reak/ai-model-learn](https://github.com/day8reak/ai-model-learn)。讲义按课号保存，学习情况按实际日期记录，动态按检索日期保存；本地保存并同步 GitHub，方便备份与共同学习。

| 学习日志 | `study-log/2026/10/2026-10-12.md` | 当天学习的课号、回答与纠正、掌握确认、暂停位置 |

同一课跨天学习时复用同一讲义，在各自日期日志中记录进展；同一天学多课时分别记录课号。休息日不自动跳课，也不补造学习记录。

## 每日节奏

- **时间**：每天北京时间 09:00（`Asia/Shanghai`）。
- **查看方式**：任务隐藏运行；上传成功后打开当天动态页，可进入当前课程、进度和学习日志。
- **当前课程**：按课号学习，一个核心问题、直观解释、具体例子、常见误区和 2–3 道自测题；默认约 20–30 分钟，可调整深度。
- **图文结合**：涉及结构、流程、形状或数据对应关系时配图，标出关键数据和箭头含义，并说明简化范围。按[图示核查约定](docs/diagrams.md)对照原始资料、检查计算并预览；优先使用内嵌 Mermaid 图，引用外部图片时标明原始来源和许可。
- **一天一课**：吃透并归档后，当天课程结束，下一课留到次日；答对自测或确认掌握不表示要求加课。
- **最新动态**：每天联网检索，优先阅读官方发布、论文和项目发布说明；每条记录发布日期、来源和对推理的实际影响。
- **学习反馈**：技术解释补充到同一课号讲义，实际作答和状态写入当天学习日志；吃透后整理正式笔记并分类保存。
- **快速跳过**：说“太简单”“已了解”或“跳过”，仍归档简明摘要并记录原因，可将下一知识点作为当天课程；若已说明今天结束或明天再学，则按该安排执行。

自动任务只在当前课号缺少讲义且已到计划日期时准备材料，已有讲义保持不变；动态独立按日生成。生成材料不代表已经学习或掌握，任务不写学习日志、不改变进度，也不因跨天跳过未完成内容。

## 学习与归档规则

1. 开始学习前读取[路线](docs/roadmap.md)、[进度](docs/progress.md)和最近[学习日志](study-log/README.md)，从当前课号继续。课程正文统一保存到 `lessons/<课号>.md`。
2. 用户确认吃透后，将定义、原理、例子、理解中的疑问与纠正、适用边界、自测和来源整理成正式笔记，标记“已掌握”。公开笔记只保留技术问题，不包含私人聊天或敏感信息。
3. 用户要求跳过时，直接生成一份简明笔记，保留定义、核心结论、适用场景、来源及跳过原因，标记“已跳过”；不要求再次确认。
4. 归档到 `notes/<分类>/<编号>-<英文短名>.md`，更新[知识索引](notes/README.md)、学习进度及当天学习日志。下一知识点标为“待学习”，默认次日开始；仅用户明确要求当天继续或跳过换课时提前推进。
5. “已跳过”可以随时重新学习。新技术先进入候选清单，补齐前置知识后再安排，避免打乱基础学习顺序。
6. 理论掌握、CPU 参考实现、NPU 验证和性能优化分别记录；跳过理论不自动视为完成实践。博客辅助理解，面经用于补充自测，技术结论核对原始资料。
7. 交互自测以对应课号讲义的“自测”章节为准，按原文和原题号出题、批改。拆解或追加的练习明确标为“补充练习”，不替代原题；需要修订正式题目时，先统一讲义并说明改动，避免聊天与 GitHub 出现不同题面。

## 动态质量要求

默认检索最近 24 小时，必要时扩展至近 7 天并明确标注“近期补充”。没有可核实的新消息时如实说明，不凑数量；搜索失败时标记失败，不声称“今日无新动态”。区分发布日期、事件日期和检索日期；同一事件不重复充当新消息。性能数字必须注明测试条件及信息来源，厂商宣称不视为本工程实测。

## 本地运行

```bash
python3 scripts/daily_learning.py --check  # 检查依赖与登录状态，不生成内容
python3 scripts/daily_learning.py          # 独立补齐当前课号讲义和当天动态，保留已有文件并同步
python3 scripts/sync_github.py             # 同步公开学习文档；需先完成仓库配置
python3 -m unittest discover -s tests -v    # 离线测试，不调用模型或 GitHub
```

自动准备讲义和动态需要 Python 3.9+、已登录的 Codex CLI 和可用网络，不需要下载模型。任务沿用当前 Codex 默认模型与账户额度。GitHub 同步另需 Git、目标仓库和可用 SSH 认证；凭证始终保留在本机。
